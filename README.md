## 게임 소개

Detective A&I는 플레이어가 발견한 증거를 직접 해석하고, 자신의 추론을 AI 형사에게 전달하는 추리 어드벤처입니다.

빵집 마을에서 벌어진 사건을 조사하며 중요한 장면을 촬영하고, 사진의 의미를 자연어로 기록합니다. AI 형사는 플레이어가 제공한 증거와 가설을 바탕으로 최종 추리를 구성하고, 평가 단계에서 사건 정답과 비교합니다. 같은 증거라도 플레이어의 해석에 따라 서로 다른 결론에 도달할 수 있습니다.
